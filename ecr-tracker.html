Notes on self-hosting

  • Self-hosted tools need a server or VM (or a cheap cloud instance) and basic maintenance (backups, security updates).
  • Map your ECR lifecycle to the tool's workflow (statuses, custom fields, approval steps).
  • If you want I can provide Docker install commands or a minimal Redmine setup script — tell me your environment.

Quick decision guide

Small teams / no infra: use the local browser app below or simple hosted issue trackers (GitHub/GitLab issues).
Growing teams / need audits: Redmine or Zammad with DB backups.
Dev heavy (code review + tasks): Phabricator (community forks) or GitLab.

ECR Tracker — browser app (Free, runs locally)

Create, edit, assign and summarize ECRs. Data saved locally (in your browser). Use "Export JSON" to backup or share.
Tip: This app stores data in your browser only. Use "Export" before switching devices or clearing browser data.
