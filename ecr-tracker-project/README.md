# ECR Tracker (Editable HTML Tool)

A simple, interactive ECR (Engineering Change Request) Tracker built using HTML, CSS, and JavaScript.

## Features
- Add, edit, and delete ECR entries
- Auto-save using browser localStorage
- CSV import/export
- Inline editing
- Priority & Status dropdowns
- Zero backend — works fully offline

## How to Use
1. Open `index.html` in your browser.
2. Add ECR using the **Add ECR** button.
3. Edit fields by clicking on them.
4. Export/Import CSV as needed.

## Deploy on GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Root folder
4. Save — your site will be live in seconds.
